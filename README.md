# Kienyeji Marketplace

Create a modern, professional, responsive website for a Kenyan mixed livestock farm. The website should look like a real established farm business, not an AI-generated template.

## FARM WEBSITE NAME

Use the farm name:

**KENP KIENYEJI FARM**

Create the website in a way that the farm name can easily be changed later.

## MAIN PURPOSE

The website should have two major purposes:

1. **Farm Products Marketplace** – customers can view animals and farm products, their prices, descriptions, availability and place an order or contact the farm.
2. **Farm Information** – customers can learn about the farm, farming practices, location, contact information and the different livestock products available.

The website should focus mainly on:

* Kienyeji chicken
* Kienyeji eggs
* Cows and fresh milk
* Sheep
* Other farm products that can be added later
